# TrackBuilder

道路と線路を自由な線形で敷設できる、Cities: Skylines 風の 3D ネットワークエディタです。TypeScript と three.js を使い、地形・道路・線路・構造物を手続き的に生成します。

## 起動

```bash
npm install
npm run dev
```

表示された URL（通常は `http://127.0.0.1:5173/`）をブラウザで開きます。起動時のサンプルでは、道路・線路・両端の駅・交差点・踏切・橋・トンネルと交通シミュレーションを確認できます。2 つの駅を路線モードで繋げば、すぐに列車を走らせられます。

## 基本操作

| 操作 | 内容 |
| --- | --- |
| 左クリック | 始点を指定し、次のクリックで確定。続けて連結できる |
| 右クリック / Esc | 現在の操作を中断 |
| B / T / Z / L / X / V | 敷設 / 駅配置 / 区画 / 路線 / 撤去 / 確認モード |
| N / M | 駅配置中に15°ずつ回転。既設の線路に置くときは取り込む番線と駅舎の向きを変える（乗車中の N は次の車両へ移動） |
| Shift | 直線・15°スナップ |
| Ctrl | スナップを一時解除 |
| PageUp / PageDown | 敷設高さを 3 m ずつ変更 |
| W / A / S / D | 視点を画面の奥・左・手前・右へ平行移動 |
| 右ドラッグ / ホイール | 視点移動 / 拡大縮小 |
| U | 地下ビュー (地形を透かし、地下の線形を実際の深さで表示) |
| F | 乗車モードを開始し、乗る車両を選択。再度押すと終了 |
| N | 乗車中に次の車両へ移動 |
| スナップの目印 | 吸い付いた点に輪が出る (水色=交差点・端点、黄=既存線形への取り付き、緑=平行、赤=踏切) |

既存線形の端点や途中を指すと、位置・接線・勾配を引き継いで接続します。線路では曲率も引き継ぎます。線路の継ぎ目 (2 本が繋がっているだけの所) は区間の途中と同じ扱いで、そこから分岐しても線路の接線に沿って分かれます。線路の分岐は接線に沿ったものだけで、折れた分岐 (直線モードで角度を付けて分けるなど) は置けません。既存線形の隣から引くと平行スナップが働きます。終点も既存線形の隣を指せば、始点の隣から終点の隣まで**既存のルートをたどって**一度に敷けます (途中でノードに分かれていても、分岐では指した向きの枝へ進みます)。区切りは基準と同じ位置に入るので、橋・トンネルの境目が隣どうしで揃います。異なる種別の線形を同じ高さで交差させると踏切になります。高架やトンネルは敷設高さを変えて作成します。引いてきた向きの後ろ寄りを指すと、接線に沿った線形は指した所まで回り込めません。そのときはプレビューに出ている**届いた所**で切って敷きます。

線路どうしを同じ高さで交差させるとダイヤモンドクロッシングになります。道路の交差点と違って浅い角度でも交われるので、平行な 2 線の間に渡り線を 2 本、互いに交わるように引けばシーサスクロッシングになります (曲線や勾配の途中でも同じです)。

交わる所の高さが 2 m 以内でずれているときは、**あとから引いた方が交点の高さに合わせます**。交点で区間が分かれ、そこを通るように勾配と縦曲線が変わります (プレビューの時点から入るので、置いた形は見えているとおりです)。線路と道路の交点だけは、どちらをあとから引いても**道路側**が合わせます (道路の上に線路を引いたときは、既設の道路の縦断の方が変わります)。合わせると最大勾配を超えてしまう所では、理由を出して敷けません。高低差が 2 m を超えていれば合わせにいかないので、立体交差にしたいときは敷設高さを 1 段 (3 m) 変えてください。

区画モードでは用途 (住宅・商業・工業) を選び、道路沿いをクリックして塗ります。マップは 5,120 m 四方で、道路の左右には舗装の外から 8 m × 10 m のマスが 2 列並びます。用途を塗ったマスは 1 つ以上まとまって 1 棟の敷地になり、塗った形がそのまま建物の大きさになります (道路沿いだけ塗れば奥行きの浅い建物、奥まで続けて塗れば大きな建物)。建物の床は道路に接する縁のいちばん高い所に合わせ、低い側は基礎を伸ばして支えます。道路を撤去すればその沿道の区画と建物も無くなり、塗った用途は地面に残るので道路を引き直せば同じ場所にまた建ちます。

駅モードでは駅名・線路数（1〜6）・ホーム数・駅長（80〜200 m）を選び、1回クリックして配置します。**空き地**を指すと新しい駅ができ、線路端から通常の線路を敷設して接続できます。**既にある線路**を指すと、その線路を取り込んで駅にします（あとから駅を足せます）。確認モードで駅を選ぶと駅名を変更でき、駅構内の線路を撤去すると駅全体が撤去されます。PageUp で高架駅を配置できますが、地下駅には対応していません。

既設の線路に置く駅は、指した所を中心に駅長ぶんの区間を切り出して構内線に変えます。**線路は 1 mm も動かない**ので、曲線の途中でも勾配の途中でもそのまま駅になり、ホーム・上屋・敷地が線路に沿って曲がります。継ぎ目をまたぐ区間は 1 本の構内線にまとめます。線路数を 2 本以上にすると足りない番線を脇に平行に作り、駅の前後で分岐器を介して本線に合流させます（待避線・行き違い設備）。N / M で「既設の線路が何番線になるか」と「駅舎と待避線を線路のどちら側に置くか」を巡回できます。高架かどうかは指した線路の高さが決めます。

置けないときは理由が出ます（駅の範囲に分岐がある、線路の端を越える、曲線に対して敷地が広すぎる、待避線を本線に繋げないなど）。駅を撤去すると、**取り込んだ線路はそのまま普通の線路として残り**、増設した番線と分岐への取り付きだけが消えます。

路線モードでは、停める駅のホームを順にクリックすると路線になり、その経路を列車が走ります。経路は車線グラフの最短経路で、どの番線を通るかは自動で決まります。線路に向きは無いので、終端駅では止まってからその場で折り返し、入ってきた線路をそのまま戻ります（渡り線や引き上げ線を敷いて一周できる形にすれば、折り返さずに走り続けます）。最後にもう一度最初の駅をクリックすると環状運転になります。Esc で 1 本の路線を区切り、次のクリックから新しい路線を引きます。路線は左のパネルに一覧で出て、クリックすると駅を足せ、✕ で消せます。線路が繋がっていない区間があれば、どこが繋がっていないかを一覧に出します。路線を引いている間だけ、経路が路線の色の帯で線路の上に出ます。

## 主な機能

- 平面線形と縦断線形を分離した道路・線路の編集
- 線路の緩和曲線、縦曲線、カント (規格の限界に近い急曲線は徐行区間として、緩和曲線もカントも入れずに素の円曲線で敷きます)
- 交差点・分岐器・踏切・ダイヤモンドクロッシングの生成 (平行 2 線の間に渡り線を 2 本引けばシーサスクロッシングになります。複線どうしも交差できます)
- 交点の高さ合わせ (高低差 2 m 以内なら、あとから引いた方が勾配と縦曲線を変えて交点の高さに揃えます。線路と道路では道路側が揃えます)
- 分岐器の造作 (トングレール・転てつ機と転てつ器標識・クロッシング・ガードレール) の表示。レールの形は変えず、実際に描かれたレールの上に載せます
- 線路の交差点は道路と違って面を持たず、道床の帯がノードまで通ります (分岐の所だけ別の板が現れることがありません)
- 平行スナップによる複線・複数車線の配置 (線路に向きは無く、1 本の軌道を両方向に走れます)
- 1〜6線の地上・高架駅、ホーム・上屋・駅舎の生成、列車の5秒停車
- 既設の線路への駅の後付け (曲線の途中でも置け、ホームが線路に沿って曲がります。待避線は分岐器で本線に合流します)
- 駅を結ぶ路線と、その経路を走る列車 (最短経路・終端での折り返し・環状運転)
- 沿道の区画 (道路の左右のグリッド) と、用途ごとの建物の生成
- 地形生成、切土・盛土、橋・トンネルの自動判定
- 敷設プレビュー (地形の下に潜る所や丘の陰も透かして表示します)
- 警告の一覧から場所へ移動 (行をクリックすると視点がその場所へ移り、輪で囲って示します。同じ内容が複数あれば、押すたびに次の場所へ)
- 最小曲線半径 (線路 50 m、生活道路 7 m など)、勾配、建築限界、重なりの事前検査
- 継ぎ目の連続性の検査 (線路が折れている所、曲率・勾配が飛んでいる所を警告に出します)
- 車線グラフ、信号、前車追従を使った車両・列車の走行
- 曲率・勾配・縦曲線半径・カントを確認する検査表示
- 都市と都市間道路の自動生成 (地形から都市を選び、通りやすい所を通して結びます)
- ダイヤモンド型・トランペット型インターチェンジのサンプル

## 都市と道路の自動生成

左のパネルの**「都市と道路を生成」**を押すと、いまの地形に合わせて都市を置き、それを結ぶ道路網を敷きます。地形を再生成してから押せば、その地形に合った別の道路網ができます。置いた都市は右のパネルに一覧で出て、行を押すとその都市へ視点が飛びます。

作り方は、実際に道路網ができていく順に並べてあります。

1. **都市を地形が選ぶ** (`src/world/cities.ts`)。まとまった平地があり、低く、水の近い所ほど点が高く、点の高い所から順に、互いに離して置きます。大都市ほど広い縄張りを取るので、**広い平野の真ん中に大都市ができ、山あいには町が点在します**。規模は人口・市街地の広さ・街路の数に効きます。
2. **街路を敷く**。町は十字路 1 つ、市は 2 本ずつ、大都市は 3 本ずつの碁盤の目で、真ん中の通りだけ規格を上げます。沿道には中心から順に商業・住宅・工業を塗るので、そのまま建物が建ちます。
3. **どこを結ぶかを決める** (`src/world/roadNetwork.ts`)。まず相対近傍グラフ (間に他の都市が割り込んでいない組) で骨格を作り、そこへ**重力モデル** (人口の積 ÷ 距離²) の大きい順に幹線を足します。足せる本数は都市の規模で決まるので、**大都市ほど多くの方向へ道が出ます**。規格も同じで、大都市どうしを結ぶ道は大通り、町へ入る道は生活道路になります。
4. **通りやすい所を通す** (`src/world/routing.ts`)。地形を 32 m の格子に落とし、起伏・水面・段差 (規格の勾配で追えるか) を通行コストにして A\* で解きます。尾根は直登せず峠へ回り込み、川は渡る所を選んで橋になります。

道が集まるのは、**既に道が通っている所を安くしている**ためです。交通量の多い幹線から先に敷くので、あとから引く道は既設路に寄ってきて、峠道や渡河点、都市の出入口で束ねられます。長く重なる区間は敷かずに手前で既設路へ取り付けるので、同じ所に 2 本並ぶことはありません。最後に、繋がらずに残った都市があれば最寄りの都市へ結び直すので、**どの都市も必ず道路で行き来できます**。

## 構成

描画用の世界は、概ね次の順序で組み立てます。

```text
交差点を解く → 交差を調べる → 構造形式を決める → 整地する → メッシュを作る
```

```text
src/
  core/       平面・縦断線形、曲線、メッシュ生成の基盤
  network/    ネットワーク、交差点、規格検査、編集、沿道の区画、路線
  terrain/    地形生成、整地、地形メッシュ
  build/      道路、線路、橋、トンネル、踏切、建物などの形状生成
  sim/        車線グラフ、信号、交通シミュレーション、路線の経路
  render/     マテリアル、車両、小物、全体の組み立て
  world/      都市の配置、都市間の結び方、地形を見た経路探索
  app/        UI、敷設ツール、確認・乗車モード、サンプル、自動生成
test/         ロジックと組み立てパイプラインのテスト
```

```bash
npm test          # テストを1回実行
npm run test:watch
npm run typecheck
npm run build     # 型チェックと本番ビルド

```

## 制限

- Undo とセーブ機能はありません。道路の上に線路を引いて道路の縦断が変わった場合、線路を撤去しても道路は元の高さに戻りません。
- 編集時はネットワークとメッシュ全体を再生成するため、数百セグメント程度を想定しています。
- 交通は簡易モデルです。車線変更・追い越し・運転操作、列車の閉塞や行き違いには対応していません。単線で列車どうしが向かい合うと、互いに手前で止まったままになります。
- 折り返しは、止まりきってからその場で向きを返す簡略化です (機回し・入換の動きは出ません)。ダイヤ・乗客・運賃はありません。1 路線あたり最大 3 編成で、経路の長さから本数を決めます。
- 同じ線路を両方向に使う路線 (終端で折り返す往復運転) は行き違いができないので、1 編成だけ走らせます。
- 停車駅の間の線路が繋がっていない場合、その区間は回送 (列車が飛ぶ) になります。
- 既設の線路に駅を置くとき、駅の範囲の縦断は両端の高さと勾配で決まる 1 本の曲線にまとめられます。途中に山や谷がある区間 (ずれが 0.3 m を超える所) には置けません。
- 待避線を本線に合流させるには、駅の前後にそれぞれ 100〜300 m ほどの本線が要ります (継ぎ目で曲率が飛ばない長さ)。足りない所では待避線を作れず、その理由が出ます。
- 信号制御は単純な2位相で、右折矢印や感応制御には対応していません。
- 平行スナップの間隔は種別ごとの固定値です。
- 区画は道路 1 本ごとに割り付けるため、街区の内側 (道路に面していない土地) には建ちません。建物の種類は用途ごとに数種類です。
- 極端に浅い交差角や、坑口に重なる交差点など、一部の配置は生成できません。
- 自動生成した道路網は、地形によっては警告 (交差点に対して短い区間、浅い交差角など) が数十件出ます。手で敷いたときと同じ検査を通しているだけなので、気になる所は撤去して引き直せます。
- 地形は 4 m 格子の高さ場なので、法肩・法尻の折れ線はその格子の大きさで多角形に見えます。
