# TrackBuilder

道路と線路を自由な線形で敷設できる、Cities: Skylines 風の 3D ネットワークエディタです。TypeScript と three.js を使い、地形・町・道路・線路・構造物を手続き的に生成します。

## 起動

```bash
npm install
npm run dev
```

表示された URL（通常は `http://127.0.0.1:5173/`）をブラウザで開きます。開くとまず地形を作るので、数秒待ちます。起動時のサンプルでは、道路・線路・両端の駅・交差点・踏切・橋・トンネルと交通シミュレーションを確認できます。2 つの駅を路線モードで繋げば、すぐに列車を走らせられます。

## 基本操作

| 操作 | 内容 |
| --- | --- |
| 左クリック | 始点を指定し、次のクリックで確定。続けて連結できる |
| 右クリック / Esc | 現在の操作を中断 |
| B / R / T / L | 道路 / 鉄道:線路 / 鉄道:駅 / 鉄道:路線 |
| Z / X / V | 区画 / 撤去 / 確認 |
| N / M | 駅配置中に15°ずつ回転（乗車中の N は次の車両へ移動） |
| Shift | 直線・15°スナップ |
| Ctrl | スナップを一時解除 |
| PageUp / PageDown | 敷設高さを 3 m ずつ変更 |
| W / A / S / D | 視点を画面の奥・左・手前・右へ平行移動 |
| 右ドラッグ / ホイール | 視点移動 / 拡大縮小 |
| U | 地下ビュー (地形を透かし、地下の線形を実際の深さで表示) |
| F | 乗車モードを開始し、乗る車両を選択。再度押すと終了 |
| N | 乗車中に次の車両へ移動 |
| スナップの目印 | 吸い付いた点に輪が出る (水色=交差点・端点、黄=既存線形への取り付き、緑=平行、赤=踏切) |

ツールは **道路 / 鉄道 / 区画 / 撤去 / 確認** の 5 つにまとまっていて、鉄道の中に
**線路・駅・路線**が並びます。道路と鉄道の違いは種別 (道路の 5 種と線路の 2 種) だけで、
敷き方は同じです。種別は行き来しても覚えているので、道路から鉄道へ移って戻っても
選び直す必要はありません。

パネルは**選んだツールの設定だけ**を出します (道路なら種別・高さ・平行スナップ、
駅なら駅の設定、というように)。ツールに依らない設定 — 表示・視点・マップ — は
下の引き出しにまとめてあり、畳んだままにできます。左下の `操作` も畳めます。

視点は注視点が地面に追い付くので、平行移動して地形の高さが変わっても
「寄れば地面に近づく」関係が保たれます。寄れるのは注視点まで 4 m まで、
カメラは地面から 2.5 m 上で止まります。平行移動の速さは注視点までの距離に
比例します (寄っているときは細かく、引いているときは大きく)。

既存線形の端点や途中を指すと、位置・接線・勾配を引き継いで接続します。線路では曲率も引き継ぎます。線路の継ぎ目 (2 本が繋がっているだけの所) は区間の途中と同じ扱いで、そこから分岐しても線路の接線に沿って分かれます。線路の分岐は接線に沿ったものだけで、折れた分岐 (直線モードで角度を付けて分けるなど) は置けません。既存線形の隣から引くと平行スナップが働きます。終点も既存線形の隣を指せば、始点の隣から終点の隣まで**既存のルートをたどって**一度に敷けます (途中でノードに分かれていても、分岐では指した向きの枝へ進みます)。区切りは基準と同じ位置に入るので、橋・トンネルの境目が隣どうしで揃います。異なる種別の線形を同じ高さで交差させると踏切になります。高架やトンネルは敷設高さを変えて作成します。引いてきた向きの後ろ寄りを指すと、接線に沿った線形は指した所まで回り込めません。そのときはプレビューに出ている**届いた所**で切って敷きます。

線路どうしを同じ高さで交差させるとダイヤモンドクロッシングになります。道路の交差点と違って浅い角度でも交われるので、平行な 2 線の間に渡り線を 2 本、互いに交わるように引けばシーサスクロッシングになります (曲線や勾配の途中でも同じです)。

交わる所の高さが 2 m 以内でずれているときは、**あとから引いた方が交点の高さに合わせます**。交点で区間が分かれ、そこを通るように勾配と縦曲線が変わります (プレビューの時点から入るので、置いた形は見えているとおりです)。線路と道路の交点だけは、どちらをあとから引いても**道路側**が合わせます (道路の上に線路を引いたときは、既設の道路の縦断の方が変わります)。合わせると最大勾配を超えてしまう所では、理由を出して敷けません。高低差が 2 m を超えていれば合わせにいかないので、立体交差にしたいときは敷設高さを 1 段 (3 m) 変えてください。

区画モードでは用途 (住宅・商業・工業) を選び、道路沿いをクリックして塗ります。マップは 20,480 m 四方で、道路の左右には舗装の外から 8 m × 10 m のマスが 2 列並びます。用途を塗ったマスは 1 つ以上まとまって 1 棟の敷地になり、塗った形がそのまま建物の大きさになります (道路沿いだけ塗れば奥行きの浅い建物、奥まで続けて塗れば大きな建物)。建物の床は道路に接する縁のいちばん高い所に合わせ、低い側は基礎を伸ばして支えます。道路を撤去すればその沿道の区画と建物も無くなり、塗った用途は地面に残るので道路を引き直せば同じ場所にまた建ちます。

駅モードでは駅名・線路数（1〜6）・ホーム数・駅長（80〜200 m）を選び、空き地を1回クリックして配置します。線路端から通常の線路を敷設して接続できます。確認モードで駅を選ぶと駅名を変更でき、駅構内の線路を撤去すると駅全体が撤去されます。PageUp で高架駅を配置できますが、地下駅には対応していません。

路線モードでは、停める駅のホームを順にクリックすると路線になり、その経路を列車が走ります。経路は車線グラフの最短経路で、どの番線を通るかは自動で決まります。線路に向きは無いので、終端駅では止まってからその場で折り返し、入ってきた線路をそのまま戻ります（渡り線や引き上げ線を敷いて一周できる形にすれば、折り返さずに走り続けます）。最後にもう一度最初の駅をクリックすると環状運転になります。Esc で 1 本の路線を区切り、次のクリックから新しい路線を引きます。路線は左のパネルに一覧で出て、クリックすると駅を足せ、✕ で消せます。線路が繋がっていない区間があれば、どこが繋がっていないかを一覧に出します。路線を引いている間だけ、経路が路線の色の帯で線路の上に出ます。

## 地形

地面の色は傾斜と標高から決め、そこへ手続き的なむら (150 m / 18 m / 1 m の 3 段) を
掛けます。テクスチャ画像は使いません。細かいむらは距離と 1 画素が覆う幅で消すので、
遠景ではちらつきません。等高線は `表示` の引き出しで切り替えられます。

地形は水文モデルで作ります。まず 40 m 格子で大陸のノイズを引き、山地の上部を
急峻にし、外周から浸水させて海面を決め、Priority-Flood で窪地を埋めながら
排水木を作ります。そこから流量を集めて盆地の出口を開削し、河道を蛇行させ、
侵食と氾濫原を作り、最後にもう一度埋め立てて全セルの排水路を確定します。
どのセルからたどっても海か盤外へ抜け、内陸に行き止まりは残りません。

編集用の高さ場 (4 m 格子) へは Catmull-Rom で細分します。40 m のセルは
20 m の河道を持てないので、川は**曲線から**この細かい格子に刻みます。
地形に刻む河床も、描く水面も、敷設の水判定も同じ曲線から引くので、
見えている水と敷ける場所が食い違いません。

`地形を再生成` を押すとシードが変わり、別の地形になります。見本のネットワークを
置く場所も地形から選び直します (橋とトンネルが 1 つずつ出て、踏切と交差点を
置ける平らな所がある所を、町の隣に探します)。

## 町

地形の適性 (平らさ・水の近さ・標高) から町の位置を決め、20,480 m 四方に
約 100 の町を置きます。町ごとに等高線に沿った格子の街路を引き、水の上・急斜面・
盤外を落として、残った所に街区と建物を割り付けます。

**視点から 900 m 以内の町は、街路が実際の道路になります**。描くときと同じ折れ線を
そのままネットワークに敷くので、近づいても線は動きません。交差点・信号・
交通シミュレーションはいつも通り働きます。離れると外しますが、プレイヤーが
繋いだ町はそのまま残します。

## 主な機能

- 平面線形と縦断線形を分離した道路・線路の編集
- 線路の緩和曲線、縦曲線、カント (規格の限界に近い急曲線は徐行区間として、緩和曲線もカントも入れずに素の円曲線で敷きます)
- 交差点・分岐器・踏切・ダイヤモンドクロッシングの生成 (平行 2 線の間に渡り線を 2 本引けばシーサスクロッシングになります。複線どうしも交差できます)
- 交点の高さ合わせ (高低差 2 m 以内なら、あとから引いた方が勾配と縦曲線を変えて交点の高さに揃えます。線路と道路では道路側が揃えます)
- 分岐器の造作 (トングレール・転てつ機と転てつ器標識・クロッシング・ガードレール) の表示。レールの形は変えず、実際に描かれたレールの上に載せます
- 線路の交差点は道路と違って面を持たず、道床の帯がノードまで通ります (分岐の所だけ別の板が現れることがありません)
- 平行スナップによる複線・複数車線の配置 (線路に向きは無く、1 本の軌道を両方向に走れます)
- 1〜6線の地上・高架駅、ホーム・上屋・駅舎の生成、列車の5秒停車
- 駅を結ぶ路線と、その経路を走る列車 (最短経路・終端での折り返し・環状運転)
- 沿道の区画 (道路の左右のグリッド) と、用途ごとの建物の生成
- 水文モデルによる地形生成 (大陸ノイズ → 山地の急峻化 → 海面の決定 → 埋め立てと排水木 → 流量集積 → 盆地の開削 → 蛇行河道 → 侵食と氾濫原 → 最終埋め立て)
- 海と川、その水面 (川は排水木から切り出した曲線で、地形に刻む河床と描く水面が同じ曲線から決まります)
- 地形から決まる町 (適性の高い所に約 100 の町を置き、等高線に沿った街路と建物を作ります。視点の近くの町は街路が実際の道路になり、交差点も交通も動きます)
- 地形から決まる森 (流量・川からの距離・河川地形・集落の適性から森の濃さを決め、木を散らします。町の幹線には街路樹が並びます)
- 切土・盛土、橋・トンネルの自動判定 (水の上は必ず橋になり、整地は水を触りません)
- 敷設プレビュー (地形の下に潜る所や丘の陰も透かして表示します)
- 警告の一覧から場所へ移動 (行をクリックすると視点がその場所へ移り、輪で囲って示します。同じ内容が複数あれば、押すたびに次の場所へ)
- 最小曲線半径 (線路 50 m、生活道路 7 m など)、勾配、建築限界、重なりの事前検査
- 継ぎ目の連続性の検査 (線路が折れている所、曲率・勾配が飛んでいる所を警告に出します)
- 車線グラフ、信号、前車追従を使った車両・列車の走行
- 曲率・勾配・縦曲線半径・カントを確認する検査表示
- ダイヤモンド型・トランペット型インターチェンジのサンプル

## 構成

描画用の世界は、概ね次の順序で組み立てます。

```text
交差点を解く → 交差を調べる → 構造形式を決める → 整地する → メッシュを作る
```

```text
src/
  core/       平面・縦断線形、曲線、メッシュ生成の基盤
  network/    ネットワーク、交差点、規格検査、編集、沿道の区画、路線
  terrain/    地形生成、整地、地形メッシュ
    hydro/    地形と水系を解く (外部依存なし・描画に依らない)
    river/    排水木から河道の曲線を作り、地形に刻む
    town/     町の位置、街路と敷地の割り付け
    vegetation.ts  森の濃さと木の散らばり
  build/      道路、線路、橋、トンネル、踏切、建物などの形状生成
  sim/        車線グラフ、信号、交通シミュレーション、路線の経路
  render/     マテリアル、車両、小物、全体の組み立て
  app/        UI、敷設ツール、確認・乗車モード、サンプル
test/         ロジックと組み立てパイプラインのテスト
```

## 開発

```bash
npm test          # テストを1回実行
npm run test:watch
npm run typecheck
npm run build     # 型チェックと本番ビルド
npm run preview   # 本番ビルドをローカル表示
```

## 制限

- Undo とセーブ機能はありません。道路の上に線路を引いて道路の縦断が変わった場合、線路を撤去しても道路は元の高さに戻りません。
- 編集時はネットワークとメッシュ全体を再生成するため、数百セグメント程度を想定しています。
- 交通は簡易モデルです。車線変更・追い越し・運転操作、列車の閉塞や行き違いには対応していません。単線で列車どうしが向かい合うと、互いに手前で止まったままになります。
- 折り返しは、止まりきってからその場で向きを返す簡略化です (機回し・入換の動きは出ません)。ダイヤ・乗客・運賃はありません。1 路線あたり最大 3 編成で、経路の長さから本数を決めます。
- 同じ線路を両方向に使う路線 (終端で折り返す往復運転) は行き違いができないので、1 編成だけ走らせます。
- 停車駅の間の線路が繋がっていない場合、その区間は回送 (列車が飛ぶ) になります。
- 信号制御は単純な2位相で、右折矢印や感応制御には対応していません。
- 平行スナップの間隔は種別ごとの固定値です。
- 区画は道路 1 本ごとに割り付けるため、街区の内側 (道路に面していない土地) には建ちません。建物の種類は用途ごとに数種類です。
- 極端に浅い交差角や、坑口に重なる交差点など、一部の配置は生成できません。
- 地形は 4 m 格子の高さ場なので、法肩・法尻の折れ線はその格子の大きさで多角形に見えます。
- 地形の生成に 3 秒ほどかかります (20,480 m 四方・2,621 万点)。その間ブラウザは止まるので、覆いを出しています。
- 地形メッシュはカメラのまわり (遠クリップ面まで) だけを持ちます。それより遠くは描かれません。遠景は 8 m・16 m 格子に間引きます。
- 木もカメラのまわりだけを持ちます。384 m までは幹と樹冠を持つ立体、そこから外は 4 角錐 1 つで、2,100 m より遠くには出しません (外縁は 3 段に間引いて、森の輪郭が直線に見えないようにしています)。
- 木と町の建物は地形のものなので、撤去も植え直しもできません。プレイヤーが線形を敷いた所の木は出なくなります。
- 湖はできません。窪地は排水路を開削してから埋めるので、埋まった窪地は水面を持たない平らな地面になります。
- 町の街路が実際の道路になるのは、視点から 900 m 以内の町だけです。それより遠い町は描いた帯と建物で見せます。切り替わるのは視界のずっと手前なので、入れ替わりは見えません。
- 町の建物は地形のものなので、撤去も区画の塗り直しもできません。プレイヤーが線形を敷いた所の建物は出なくなります。
- 町の街路にプレイヤーが繋いだ場合、その町は離れても残ります (敷いたものを消さないため)。
