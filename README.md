# TrackBuilder

道路と線路を自由な線形で敷設できる、Cities: Skylines 風の 3D ネットワークエディタです。TypeScript と three.js を使い、地形・道路・線路・構造物を手続き的に生成します。

## 起動

```bash
npm install
npm run dev
```

表示された URL（通常は `http://127.0.0.1:5173/`）をブラウザで開きます。起動時のサンプルでは、道路・線路・駅・交差点・踏切・橋・トンネルと交通シミュレーションを確認できます。

## 基本操作

| 操作 | 内容 |
| --- | --- |
| 左クリック | 始点を指定し、次のクリックで確定。続けて連結できる |
| 右クリック / Esc | 現在の操作を中断 |
| B / S / Z / C / X / V | 敷設 / 駅配置 / 区画 / シーサス / 撤去 / 確認モード |
| N / M | 駅配置中に15°ずつ回転（乗車中の N は次の車両へ移動） |
| Shift | 直線・15°スナップ |
| Ctrl | スナップを一時解除 |
| PageUp / PageDown | 敷設高さを 3 m ずつ変更 |
| 右ドラッグ / ホイール | 視点移動 / 拡大縮小 |
| U | 地下ビュー (地形を透かし、地下の線形を実際の深さで表示) |
| F | 乗車モードを開始し、乗る車両を選択。再度押すと終了 |
| N | 乗車中に次の車両へ移動 |
| スナップの目印 | 吸い付いた点に輪が出る (水色=交差点・端点、黄=既存線形への取り付き、緑=平行、赤=踏切) |

既存線形の端点や途中を指すと、位置・接線・勾配を引き継いで接続します。線路では曲率も引き継ぎます。既存線形の隣から引くと平行スナップが働き、異なる種別の線形を同じ高さで交差させると踏切になります。高架やトンネルは敷設高さを変えて作成します。

区画モードでは用途 (住宅・商業・工業) を選び、道路沿いをクリックして塗ります。マップは 5,120 m 四方で、道路の左右には舗装の外から奥行き 20 m の区画が並びます。用途を塗った区画には建物が建ち、道路を撤去すればその沿道の区画と建物も無くなります。塗った用途は地面に残るので、道路を引き直せば同じ場所にまた建ちます。

駅モードでは駅名・線路数（1〜6）・ホーム数・駅長（80〜200 m）を選び、空き地を1回クリックして配置します。線路端から通常の線路を敷設して接続できます。確認モードで駅を選ぶと駅名を変更でき、駅構内の線路を撤去すると駅全体が撤去されます。PageUp で高架駅を配置できますが、地下駅には対応していません。

## 主な機能

- 平面線形と縦断線形を分離した道路・線路の編集
- 線路の緩和曲線、縦曲線、カント
- 交差点・分岐器・踏切・シーサスクロッシングの生成
- 平行スナップによる複線・複数車線の配置
- 1〜6線の地上・高架駅、ホーム・上屋・駅舎の生成、列車の5秒停車
- 沿道の区画 (道路の左右のグリッド) と、用途ごとの建物の生成
- 地形生成、切土・盛土、橋・トンネルの自動判定
- 最小曲線半径、勾配、建築限界、重なりの事前検査
- 車線グラフ、信号、前車追従を使った車両・列車の走行
- 曲率・勾配・縦曲線半径・カントを確認する検査表示
- ダイヤモンド型・トランペット型インターチェンジのサンプル

## 構成

描画用の世界は、概ね次の順序で組み立てます。

```text
交差点を解く → 交差を調べる → 構造形式を決める → 整地する → メッシュを作る
```

```text
src/
  core/       平面・縦断線形、曲線、メッシュ生成の基盤
  network/    ネットワーク、交差点、規格検査、編集、沿道の区画
  terrain/    地形生成、整地、地形メッシュ
  build/      道路、線路、橋、トンネル、踏切、建物などの形状生成
  sim/        車線グラフ、信号、交通シミュレーション
  render/     マテリアル、車両、小物、全体の組み立て
  app/        UI、敷設ツール、確認・乗車モード、サンプル
test/         ロジックと組み立てパイプラインのテスト
```

## 開発

```bash
npm test          # テストを1回実行
npm run test:watch
npm run typecheck
npm run build     # 型チェックと本番ビルド
npm run preview   # 本番ビルドをローカル表示
```

デバッグ時は `window.trackBuilder` から主要オブジェクトを参照できます。

## 制限

- Undo とセーブ機能はありません。
- 編集時はネットワークとメッシュ全体を再生成するため、数百セグメント程度を想定しています。
- 交通は簡易モデルです。車線変更・追い越し・運転操作、列車の閉塞や行き違いには対応していません。
- 信号制御は単純な2位相で、右折矢印や感応制御には対応していません。
- 平行スナップの間隔は種別ごとの固定値です。
- 区画は道路 1 本ごとに割り付けるため、街区の内側 (道路に面していない土地) には建ちません。建物の種類は用途ごとに数種類です。
- 極端に浅い交差角や、坑口に重なる交差点など、一部の配置は生成できません。
- 地形は 4 m 格子の高さ場なので、法肩・法尻の折れ線はその格子の大きさで多角形に見えます。
